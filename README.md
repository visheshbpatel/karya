# Karya

Karya is a task management application designed to make managing everyday work simple and flexible.

The project starts as a lightweight Todo application and is being built with a focus on clean architecture, practical functionality, and the ability to evolve into a larger productivity platform.

## Current Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Set task priority
- Partially update tasks

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite


## Project Status

Karya is currently in active development.

The initial version focuses on building a reliable core task-management system before adding integrations and more advanced functionality.
